# 🌐 Exploring Pakistan

## 📖 Project Overview
This project is a **front page website** created using **HTML and CSS** as a semester project for the **ICT course** in the **1st semester of BSCS**.  

The website is titled **"Exploring Pakistan"** and showcases the beauty, culture, and key information about Pakistan in a simple and visually appealing design.

---

## 🎯 Objective
The main objectives of this project are:

- To practice **HTML and CSS** skills  
- To design a clean and responsive **single-page website**  
- To present information about Pakistan in a structured way  
- To gain hands-on experience in **web development fundamentals**

---

## 🛠 Technologies Used
- **HTML5** – Structure and content of the webpage  
- **CSS3** – Styling, layout, and visual design
